# AUVIX Lead Agent

Инструмент для обработки списка потенциальных клиентов студии AUVIX: проверяет
сайт лида, генерирует персонализированный холодный текст и собирает всё в
таблицу для отправки вручную и подсчёта потенциальной выручки.

**Важно про сбор самого списка.** Этот инструмент не ищет бизнесы сам (сбор
через 2ГИС/Яндекс.Карты и т.п. требует прямого доступа в интернет, которого
может не быть в текущей среде запуска) — на вход он принимает уже собранный
CSV-файл. Список можно выгрузить вручную из 2ГИС/Яндекс.Карт, скопировать из
таблицы или получить любым другим способом.

## Установка

```bash
cd lead-agent
pip install -r requirements.txt
export ANTHROPIC_API_KEY="ваш_ключ"   # нужен только если не используете --skip-pitch
```

## Формат входного CSV

Обязательные колонки: `name`, `niche`, `city`.
Опциональные: `website`, `phone`, `telegram`, `email`.

Пример — `sample_leads.csv`.

## Запуск

```bash
python main.py sample_leads.csv --out result.xlsx
```

Без вызова Claude API (только проверка сайтов и расчёт потенциала):

```bash
python main.py sample_leads.csv --out result.xlsx --skip-pitch
```

## Что делает скрипт

1. Для каждого лида проверяет сайт (`enrich.py`): жив ли, есть ли форма
   заявки — по этому определяется, насколько лид "горячий".
2. Подбирает релевантный пакет AUVIX и оценивает потенциальную выручку
   (`report.py`), на основе прайса из `studio_profile.json`.
3. Генерирует черновик персонализированного холодного текста через Claude
   API (`pitch.py`) — с учётом ниши, найденной проблемы и УТП студии.
4. Записывает всё в `.xlsx`: контакты, статус сайта, рекомендуемый пакет,
   потенциальная выручка, черновик текста, итоговая сумма по всем лидам внизу.

Отправка текстов остаётся ручной — скрипт только готовит черновики.

## Настройка модели

По умолчанию используется `claude-opus-5`. Переопределить можно переменной
окружения `AUVIX_PITCH_MODEL` (например, `claude-sonnet-5` — дешевле для
больших объёмов лидов).
