Эта страница объясняет, какие данные собирает сайт AUVIX Studio (далее — «сайт»), зачем это нужно и как ими распоряжается Иван — самозанятый (плательщик налога на профессиональный доход), оказывающий услуги в сфере digital-маркетинга и разработки (далее — «исполнитель», «я»). Используя форму заявки или чат на сайте, вы соглашаетесь с условиями ниже.

Какие данные собираются

Через форму «Оставить заявку»:

  • имя;
  • номер телефона;
  • контакт в Telegram/Instagram или другой соцсети (если указан);
  • описание бизнеса, выбранная услуга, бюджет, платформы и комментарий — если вы их заполнили.

Через чат-ассистента на сайте — текст сообщений, которые вы отправляете, для формирования ответа.

Автоматически, с помощью Яндекс.Метрики — технические данные о посещении (страницы, действия, приблизительная геолокация, тип устройства) для понимания того, как люди пользуются сайтом. Эти данные обезличены и не привязаны напрямую к вашему имени.

Зачем это нужно

  • чтобы связаться с вами по заявке, обсудить задачу и предложить решение;
  • чтобы чат-ассистент мог ответить на вопрос по услугам и ценам;
  • чтобы понимать, какие разделы сайта работают, а какие нужно улучшить.

Данные не используются для автоматических решений и не продаются третьим лицам.

Как обрабатываются данные

Заявка с формы уходит напрямую в Telegram исполнителя через технический промежуточный сервис (Cloudflare Workers) — это происходит мгновенно, отдельной базы с анкетами клиентов сайт не ведёт. Сообщения в чате обрабатываются похожим образом для генерации ответа и не хранятся дольше, чем нужно для работы диалога.

Для аналитики посещаемости используется Яндекс.Метрика — у неё есть собственная политика обработки данных: yandex.ru/legal/confidential.

Кто ещё видит данные

Данные не передаются третьим лицам для маркетинга или перепродажи. Технические подрядчики, через которых проходят данные (Cloudflare — для доставки заявки, Яндекс — для аналитики), обрабатывают их только как часть предоставления своей инфраструктуры.
